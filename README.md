# Adam Bodor

I'm not an engineer. I build small tools with Claude Code when something in my work annoys me, mostly around editing in DaVinci Resolve. The ones here are the ones I still use.

### Tools

- [edit-time](https://github.com/adam-boss/edit-time): logs how long you spend editing, per project. No timers.
- [resolve-scripting-notes](https://github.com/adam-boss/resolve-scripting-notes): what the DaVinci Resolve API does that the docs don't say. Also works as a Claude Code skill.
